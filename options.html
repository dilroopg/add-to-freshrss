Right-click any link → Add to FreshRSS.

FreshRSS
Base URL only - no trailing slash, no /i/ path, no /api/ path.
Off (default): the feed is added by opening FreshRSS's own add page in a background tab — no password needed.
On: the feed is submitted straight from here and you get a notification instead.
Silent mode only. Settings page (default) jumps to where you can rename, move or delete the feed. Feed's own link opens the address it was subscribed from — the older behaviour.
API credentials (for silent mode)
Not your login password. Set one in FreshRSS under Settings → Profile → API management.
